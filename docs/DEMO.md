# Проверка проекта из репозитория

Итоговый материал для самостоятельного просмотра проекта: [руководство пользователя и проверяющего](USER_GUIDE.md).

В нём описаны запуск, доступы, профиль, рекомендации, личный план, HR и импорт с ожидаемыми результатами. Фактические результаты и ограничения — в [QA_REPORT.md](QA_REPORT.md), открытые дефекты — в [BUG_REPORT.md](BUG_REPORT.md).

Этот файл сохранён как переход со старых ссылок на демо-сценарий. Для текущей сдачи команда готовит проект и документацию в репозитории.
