# Career Quest — план ручной проверки и регрессии

Актуализирован для кода **e4a146e**: личный план и импорт с подтверждением. Фактические результаты — в [QA_REPORT.md](QA_REPORT.md). [Исходный план первого этапа](archive/2026-09-23-stage1/QA_PLAN.md) сохранён отдельно.

## Подготовка

1. Зафиксировать commit: `git rev-parse HEAD`.
2. Запустить отдельный стенд по [README](../README.md); для исходных чисел использовать свежую базу. Рабочую базу команды не сбрасывать.
3. Войти как `employee` и `hr` по очереди. Начальные доступы указаны в README.
4. Зафиксировать режим: настоящий AI либо явно обозначенный резерв. Успех резервного режима не подтверждает LLM.
5. Подготовить [3 профиля и историю](qa/2026-09-23/fixtures/EXPECTED.md). Ожидания рассчитаны по синтетическому киту.
6. Для каждого сценария записать статус, факт, доказательство и ID бага. «Не проверено» использовать, если сценарий не выполнялся.
