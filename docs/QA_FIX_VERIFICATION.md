## Поведение HR и импорта

«Без рекомендованного шага» означает отсутствие полезного доступного кандидата вне личного плана. Это не оценка сотрудника. Причины разделяются: нет цели, требования по навыкам выполнены, шаги уже в плане, подходящих активностей нет.

Участие группируется по событиям **для той же выборки сотрудников**, включая выбранные фильтры. Окно — от даты среза минус 90 дней до даты среза включительно. Число участников внутри мероприятия уникально; статусы считаются по записям истории. Обязательные мероприятия показываются с отдельной меткой, без игровых наград.

CSV принимает все 10 именованных столбцов исходного `activity_history.csv`; порядок может отличаться. Пропущенные, лишние или повторяющиеся имена столбцов отклоняются. Повтор того же record_id обновляет запись. Два completed добровольного неповторяемого события для одной пары сотрудник/мероприятие запрещены. Для EV_036 разрешены разные даты. Повторные обязательные мероприятия исходного кита сохраняются — это уже существующее допущение проекта.
