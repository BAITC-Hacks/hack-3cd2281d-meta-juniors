## Окружение и воспроизводимость

- Windows; Docker, Python 3.12, Django 5.2.17, PostgreSQL 16; встроенный браузер Codex.
- Отдельный Compose-проект `career-quest-qa-stage2-20260923`, web **127.0.0.1:8011**, PostgreSQL **5444**, отдельный volume.
- Начало: 200 сотрудников, 2743 истории; дата среза данных **2026-10-01**.
- Конец: **203 сотрудника, 2750 историй, revision=2**. У E0028 — 18 историй и один завершённый шаг EV_009.
- 2750 = 2743 исходных + 6 импортированных + 1 начатый и затем завершённый шаг. Завершение обновляет запись, а не создаёт вторую.
- Сотрудник `employee` (E0028), HR `hr`; стандартные демонстрационные доступы из README.
- Штатные и дополнительные тесты запускались последовательно в отдельной `test_career_quest`, которую Django удалил после каждого прогона.
- Исполнитель: Codex по запросу участника команды. UI проверен инструментом браузера; multipart-импорт — Python HTTP-клиентом с настоящей сессией и CSRF.
- Файловый диалог браузера не проверен: инструмент не поддерживает загрузку файлов. HTTP-проверка подтверждает серверную часть формы, а не работу системного диалога.
- При первом открытии до окончания bootstrap сервер был недоступен. После готовности проверка выполнена через 127.0.0.1; localhost в этом новом браузерном прогоне не подтверждён.

## Повторный запуск

Из корня репозитория, на отдельном QA-стенде:

```powershell
$env:APP_PORT = '8011'
$env:POSTGRES_PORT = '5444'
docker compose --project-name career-quest-qa-stage2-20260923 up --build -d
docker compose --project-name career-quest-qa-stage2-20260923 exec -e OPENAI_API_KEY= web python manage.py test quest --verbosity 2 --noinput
docker compose --project-name career-quest-qa-stage2-20260923 cp docs/qa/2026-09-23-stage2/qa_stage2.py web:/tmp/qa_stage2.py
docker compose --project-name career-quest-qa-stage2-20260923 exec -e OPENAI_API_KEY= -e PYTHONPATH=/tmp:/app web python manage.py test qa_stage2.Stage2Audit --verbosity 2 --noinput
```

Сценарий HTTP рассчитан на **свежий** стенд 8011; повтор на уже импортированных профилях намеренно не соответствует начальному ожиданию «404». Перезапуск Compose сохраняет данные. Для нового прогона создать отдельный проект/volume и свободные порты; рабочую базу команды не сбрасывать.
