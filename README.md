# Career Quest · Meta Juniors

AI-навигатор развития сотрудников для кейса Halyk Bank, HackAlem AI 2026.

Профиль и история → актуальные навыки → карьерная цель → 1–3 объяснимых шага → обновление прогресса. HR получает срез дефицитов и вовлечённости. Дополнительные профили жюри загружаются через интерфейс.

## Быстрый запуск

Требуется Docker Desktop / Docker Engine с Compose. Из корня репозитория:

```sh
docker compose up --build -d
```

Открыть http://localhost:8000. Первый запуск применяет миграции, импортирует `data/` и создаёт демо-аккаунты. Повторный запуск сохраняет данные в PostgreSQL volume.

| Роль | Логин | Пароль по умолчанию |
|---|---|---|
| Сотрудник (E0028) | employee | career-demo-2026 |
| HR | hr | career-demo-2026 |

На странице входа есть кнопки для обеих демо-ролей. Данные синтетические. Стандартная конфигурация рассчитана на локальную демонстрацию.

```sh
docker compose ps
docker compose logs --tail=50 web
docker compose down
```

Если порт занят, задайте `APP_PORT=8001` в `.env` и откройте http://localhost:8001. `down` сохраняет данные; не добавляйте `-v`, если хотите их сохранить.

## Подключение AI

Скопировать `.env.example` в `.env` (в PowerShell: `Copy-Item .env.example .env`). Указать локально:

```dotenv
OPENAI_API_KEY=ваш_API_ключ
OPENAI_MODEL=gpt-4.1-mini
```

Затем `docker compose up -d --force-recreate web`. Ключ не передаётся в браузер и не коммитится. Требуется именно API-ключ OpenAI Platform, а не промокод ChatGPT.

Без ключа или при ошибке провайдера приложение работает с явно помеченным резервным многофакторным подбором. Реальный LLM выбирает события и подтверждающие факты; сервер проверяет их допустимость. Модель настраивается через `.env`.

## Локальная разработка: Windows / PowerShell

Python 3.12, виртуальная среда, база на выбор:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
Copy-Item .env.example .env
.\scripts\run-local.ps1
```

Без DB_HOST используется SQLite для быстрого локального старта. Для PostgreSQL:

```powershell
docker compose up -d db
```

В `.env` задать `DB_HOST=localhost`, `DB_PORT=5433`, затем перезапустить локальное приложение. PostgreSQL/Compose используют одну схему моделей и миграций; интеграционные тесты запускаются на обеих БД. Локальный сервер: http://127.0.0.1:8000.

## Проверки

```powershell
.\.venv\Scripts\python.exe manage.py test
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\ruff.exe check .
```

В контейнере на PostgreSQL:

```sh
docker compose exec web python manage.py test
```

Тесты используют отдельную тестовую базу. Покрывают пересчёт после аттестации, потолки навыков, допустимость мероприятий, дополнительный импорт, атомарность ошибок, права и CSRF, идемпотентность завершения, проверку ответа AI и резервный режим. Вызовы модели в тестах заменены контролируемыми ответами: это не live-проверка API.

## Импорт и дата данных

- Исходный набор в `data/`: 200 профилей, 40 мероприятий, 60 навыков, 32 профиля требований, 2 743 записи истории.
- Дата среза: **2026-10-01**; она используется вместо системной даты.
- HR → «Загрузка данных»: дополнительные employees.json и activity_history.csv. Можно отдельно обновить каталог skills/events. Формат — как в [README датасета](data/README.ru.md).
- Весь импорт — одна транзакция. Повторные ID в файле отклоняются; существующие записи обновляются по ID. Повторный импорт не дублирует историю.
- CLI: `python manage.py import_dataset --directory path/to/files`.
- Дополнительные профили сразу доступны HR; отдельная учётная запись сотрудника автоматически не создаётся.

## Что важно для оценки

Пример E0028: System Design пересчитывается с 2 до 3 после EV_006. EV_005 не даёт дальнейшего прироста и исключается. Для Senior нужен уровень 4, но доступного события для этого разрыва сейчас нет — приложение показывает ограничение каталога. Другие подходящие шаги учитывают историю и пользу для цели.

Employee видит только свой профиль; HR видит команду и импорт. Публичного рейтинга нет. «Завершить в демо» моделирует событие на дату среза и не подтверждает реальное обучение. При DEMO_MODE=0 симуляция отключается. Подробные допущения — в архитектуре.

Прототип не содержит промышленную SSO/LMS-интеграцию, полную казахскую локализацию и измеренный бизнес-эффект. Правила резервного ранжирования — гипотезы команды. Задержку live-AI необходимо проверять с рабочим ключом.

## Проверка на другом устройстве

Для запуска у коллеги достаточно клонировать официальный репозиторий и выполнить Compose-команду. Для доступа к вашему компьютеру по общей сети задайте `HOST_BIND=0.0.0.0` и добавьте IP компьютера в `DJANGO_ALLOWED_HOSTS`, сохранив localhost и 127.0.0.1, затем пересоздайте web. Используйте только в сети команды: демо-пароли приведены выше.
