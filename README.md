# Career Quest

Веб-приложение помогает сотруднику увидеть навыки, понять требования следующего грейда и получить персональные рекомендации по развитию.

## Возможности

- Показ профиля, навыков и текущего грейда.
- Рекомендации по следующим шагам развития.
- Объяснение причин рекомендации.
- Обновление прогресса после активности.
- HR-экран с проседающими компетенциями.

## Команда

- Участник 1 — backend, AI-интеграция, инфраструктура.
- Участник 2 — требования, тестовые данные и проверка рекомендаций.
- Участник 3 — QA, документация и демо-сценарий.

## Запуск

Инструкции будут добавлены после готовности проекта.

## Проверка

1. Открыть приложение.
2. Выбрать или загрузить профиль сотрудника.
3. Получить рекомендации.
4. Проверить объяснение рекомендации.
5. Отметить выполнение активности.
6. Убедиться, что прогресс навыков обновился.
7. Открыть HR-экран и проверить срез компетенций.
